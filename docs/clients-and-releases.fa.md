# برنامه‌های بومی و فرایند انتشار

[English](clients-and-releases.md) | [مستندات](README.fa.md)

## برنامهٔ مشترک و میزبان‌ها

رابط React در استقرار وب، میزبان Electron در `apps/desktop/` و میزبان Android/Capacitor در `apps/mobile/` مشترک است. این میزبان‌ها به API مرکز با HTTPS متصل‌اند، پایگاه مستقل اطلاعات بیمار ندارند و ثبت نوبت آفلاین را تضمین نمی‌کنند. اتصال اولیه بدون اعتبارنامه از `/api/v1/client-info` استفاده می‌کند و ورود فقط پس از انتخاب سرور معتبر انجام می‌شود.

نسخهٔ دسکتاپ از پل جداشدهٔ Electron و ذخیرهٔ نشست رمزگذاری‌شده توسط سیستم‌عامل استفاده می‌کند. اندروید مخزن اعتبارنامهٔ مبتنی بر Android Keystore و سیاست شبکه دارد. قطع موقت اتصال باید امکان تلاش مجدد بدهد و موفقیت ساختگی اعلام نکند؛ خروج باید بازگشت اعتبارنامه را حتی در صورت عدم دسترسی به سرور برای ابطال راه دور مسدود کند.

## ساخت محلی

ابتدا وابستگی‌های وب را نصب و `npm --prefix frontend run build` را اجرا کنید. سپس:

~~~sh
npm --prefix apps/desktop ci
npm --prefix apps/desktop run prepare:web
npm --prefix apps/desktop test
npm --prefix apps/desktop run build:win
npm --prefix apps/mobile ci
npm --prefix apps/mobile run sync
npm --prefix apps/mobile run build:debug
~~~

بسته‌بندی ویندوز به میزبان ساخت مناسب ویندوز نیاز دارد. اندروید به Java 21، Android SDK و Gradle wrapper نیازمند است؛ همهٔ دستورها روی هر دستگاهی قابل اجرا نیستند. فایل‌های ساخته‌شده زیر `artifacts/` قرار می‌گیرند و نباید commit شوند.

## CI و توزیع

`.github/workflows/verify.yml` کنترل‌های اصلی کیفیت را اجرا می‌کند. `.github/workflows/release-apps.yml` بستهٔ وب تأییدشده را می‌گیرد و NSIS/portable ویندوز و APK/AAB اندروید می‌سازد. پرچم‌های اختیاری امضا به گواهی ناشر/کلید واقعی و بررسی امضا نیاز دارند. امکان ایجاد انتشار **پیش‌نویس امضاشده** وجود دارد، نه انتشار خودکار در فروشگاه یا راه‌اندازی آزادانهٔ عملیاتی.

`node scripts/check-versions.mjs` را برای تطبیق نسخهٔ بسته‌ها، Python و تصویر Compose اجرا کنید. بستهٔ بی‌امضا فقط خروجی آزمون است. پیش از توزیع، هش و امضا، نصب تازه، ارتقا، ورود/خروج، مجوز میکروفون، قطع اتصال، حذف برنامه، بازگردانی و دستگاه‌های فیزیکی نماینده بررسی شوند. رازهای امضای انتشار از رازهای سرور مستقل و با دسترسی محدود بمانند.
