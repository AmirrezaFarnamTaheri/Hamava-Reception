# مستندات هم‌آوا

[English](README.md) | [صفحهٔ اصلی پروژه](../README.fa.md)

اسکرین‌شات‌ها، فایل‌های JUnit و گزارش‌های آزمایش هر اجرا عمداً از مستندات نگهداری‌شده حذف می‌شوند؛ جای آن‌ها در **خروجی‌های موقت GitHub Actions** یا مخزن شواهد با مدیریت بهره‌بردار است که به اجرای مشخص و شناسهٔ commit ارجاع می‌دهد. تاریخچهٔ Git گزارش‌های گذشته را حفظ می‌کند، بی‌آنکه آن نتایج کهنه به‌عنوان وضعیت فعلی معرفی شوند.

داده‌های `docs/evidence/` و `fixtures/research/` **ساختگی و آزمایشی‌اند** و گزارش پیشرفت محصول نیستند. متن حقوقی `docs/licenses/` متعلق به تأمین‌کننده است و ترجمه یا دستکاری نمی‌شود.

## ترتیب منابع معتبر

1. کد، مهاجرت‌های نسخه‌دار و آزمون‌ها رفتار پیاده‌شده را مشخص می‌کنند.
2. مسیر `/openapi.json` در سرور در حال اجرا، قرارداد واقعی همان استقرار را نشان می‌دهد.
3. این راهنما کاربرد، محدودیت و روش کار بهره‌بردار را توضیح می‌دهد.
4. اجرای مشخص CI و شواهد تأییدشدهٔ خارجی نشان می‌دهند چه چیزی واقعاً آزموده شده است. نه گزارش تاریخی و نه این راهنما، تأیید مرکز واقعی نیست.

## به‌روزرسانی مستندات

نسخهٔ فارسی و انگلیسی را در یک PR تغییر دهید. مسیرها، دستورها، نام endpoint، پرچم‌ها و محدودیت‌ها باید یکسان بمانند. پیش از ارسال تغییر، `node scripts/check-docs.mjs` و `node --test scripts/check-docs.test.mjs` را اجرا کنید. اگر رفتاری هنوز احراز نشده است، محدودیت را شفاف بنویسید و نتیجهٔ موفقیت‌آمیز نسازید.
