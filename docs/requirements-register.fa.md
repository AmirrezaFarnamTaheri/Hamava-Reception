# تاریخچهٔ نیازمندی‌ها و مرجع معتبر

[English](requirements-register.md) | [مستندات](README.fa.md)

فایل ماشین‌خوان `requirements.json` به‌عنوان فهرست تفصیلی اولیهٔ نیازمندی‌ها حفظ شده است. این فایل **فرادادهٔ تاریخی محدودهٔ پروژه** است، نه ادعای به‌روز دربارهٔ تأیید تمام قابلیت‌ها. کد، آزمون‌ها، CI جاری و پذیرش مستقل مرکز/تأمین‌کننده وضعیت واقعی پیاده‌سازی و آمادگی را تعیین می‌کنند.

خروجی‌های تکراری، خلاصه‌های وظایف و گزارش‌های موقت از درخت مستندات نگهداری‌شده حذف شده‌اند، اما نسخه‌های قبلی در تاریخچهٔ Git بازیافت می‌شوند. فایل‌های CSV قدیمی نباید به‌عنوان مراجع رقیب دوباره ساخته شوند. شرح معتبر محصول، معماری، API و عملیات در راهنماهای جاری است. تغییر نیازمندی باید با اصلاح آگاهانهٔ JSON و شاهد کد/آزمون/پذیرش هر مورد همراه باشد و وابستگی بیرونی را خودکار کامل اعلام نکند.
