# رابط وب مشترک هم‌آوا

[English](README.md) | [پروژه](../README.fa.md) | [راهنمای توسعه](../docs/development.fa.md)

برنامهٔ React/TypeScript/Vite محیط پذیرش راست‌به‌چپ فارسی و مسیرهای عمومی مراجعه‌کننده را فراهم می‌کند. این رابط به سرویس FastAPI در `/api/v1` وصل می‌شود و هرگز پس از خطای شبکه موفقیت ساختگی نشان نمی‌دهد.

## اجرای محلی

وقتی سرور در `http://127.0.0.1:8000` فعال است، در پوشهٔ `frontend/` اجرا کنید:

~~~sh
npm ci
npm run dev
~~~

برای ساخت بستهٔ ایستا `npm run typecheck` و `npm run build` را اجرا کنید. سرور در صورت وجود، فایل‌های `frontend/dist/` را ارائه می‌کند. آزمون‌های مرورگر باید از API نمایشیِ جداگانه استفاده کنند: بعد از ساخت، از ریشهٔ مخزن `python scripts/ci_ui.py test:ui test:workflows test:conversation test:privacy-notice` را اجرا کنید.

## ناوبری و محدودیت‌ها

امکانات کارکنان شامل امروز، نوبت‌ها، وظایف، تماس‌ها، مدیریت و کنترل‌های مجوزدار است. صفحهٔ عمومی `/talk/:slug` پیش از ایجاد نشست، رضایت پردازش می‌گیرد. پیوند `/respond/:id#secret` راز پاسخ را در حافظه نگه می‌دارد. ناوبری موبایل بر امروز/وظایف/تماس‌ها/بیشتر تأکید دارد. تنظیم اتصال پیش از بررسی سازگاری، اعتبارنامه نمی‌فرستد؛ اندروید از HTTPS استفاده می‌کند. مجوز و مرجع نوبت روی سرور می‌ماند. در نبود صوت یا RTC، متن کار می‌کند؛ رابط ادعای نوبت‌دهی آفلاین یا تأیید دستگاه واقعی ندارد.

قراردادهای نگهداری‌شده در [رفتار محصول](../docs/product.fa.md)، [معنای API](../docs/api.fa.md) و [بسته‌بندی بومی](../docs/clients-and-releases.fa.md) آمده‌اند.
