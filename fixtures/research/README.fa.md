# داده‌های ساختگی پژوهش

[English](README.md) | [پژوهش](../../docs/research.fa.md)

این فایل‌ها شامل تن‌های صوتیِ غیرگفتاری و داده‌های متنی، تعداد و قیمتِ ساختگی و قطعی هستند. هیچ تماس‌گیرنده، مرکز، رضایت واقعی، آزمون آکوستیک، قیمت بازار یا نتیجهٔ بالینی حقیقی در آن‌ها وجود ندارد. فیلدهای رضایت و بازبینی صرفاً نمونهٔ آزمایشی‌اند. متن نمونه، رونویسی صدای تن‌ها نیست. از این داده‌ها برای اثبات دقت بازشناسی گفتار فارسی یا بهبود مدل استفاده نکنید. ابزار آموزش، دادهٔ ساختگی را جز در حالت صریح آزمون دود (smoke test) رد می‌کند.

برای ساخت نسخهٔ تازه `python scripts/make_synthetic_fixtures.py /tmp/new-synthetic-fixtures` را اجرا کنید. مقصد باید تازه یا خالی باشد؛ دستور روی داده‌های موجود نمی‌نویسد.

## کاربرد نمونه‌ها

این داده‌ها برای آزمون فرادادهٔ مجوز، لغو رضایت، خواندن فایل، حذف اطلاعات حساس، تقسیم مجموعه‌داده، ساخت گزارش ارزیابی و محاسبهٔ ظرفیت یا هزینه بدون استفاده از اشخاص واقعی مناسب‌اند. صوت‌ها تن هستند، نه گفتار؛ بنابراین نباید متن ساختگی را مانند رونویسی صدای انسان با آن‌ها مقایسه کرد.

از ریشهٔ مخزن نسخهٔ تازه بسازید:

~~~sh
python scripts/make_synthetic_fixtures.py /tmp/new-synthetic-fixtures
~~~

مقصد باید تازه یا خالی باشد. پیش از استفاده از ابزار پژوهش، فهرست داده و پرچم‌های مجوز را بررسی کنید. برای ضبط واقعی و دارای مجوز، [راهنمای پژوهش](../../docs/research.fa.md) را بخوانید. ورودی ساختگی می‌تواند آزمون دود انجام دهد، اما کیفیت بازشناسی فارسی یا ارزش واقعی برای مرکز را نمی‌سنجد.
