# داده‌های ساختگی پژوهش

[English](README.md) · [راهنمای پژوهش](../../docs/research.fa.md)

فایل‌های این پوشه ورودی آزمون تکرارپذیر هستند. متن، قیمت، افراد و رکوردهای مجوز به موارد خیالی تعلق دارند. شش فایل WAV حاوی تن صوتی غیرگفتاری‌اند. متن کنار آن‌ها **رونویسی صوت نیست**.

## برای هر آزمون کدام فایل را برداریم؟

| فایل | کاربرد |
| --- | --- |
| `manifest-input.jsonl` | رکوردهای صوت، فراداده، بررسی حق استفاده و آماده‌سازی مجموعه‌داده |
| `withdrawals.json` | حذف رکوردهایی که رضایتشان پس گرفته شده |
| `speech-predictions.jsonl` | خواندن نتیجهٔ ارزیابی و گزارش خطا |
| `training-recipe.template.json` | اعتبارسنجی دستور آموزش بدون اجرای آموزش واقعی |
| `capacity-input.json` | محاسبهٔ سناریوی صف و نیروی انسانی |
| `economics-input.json` | محاسبهٔ دقیق هزینه با نرخ ساختگی |
| `pilot-cohorts.jsonl` | منطق گزارش گروه پایه و پایلوت |
| `audio/synthetic-tone-*.wav` | بررسی خواندن و قطعه‌بندی فایل صوتی |

این نمونه‌ها نشان می‌دهند خواندن فایل و محاسبه روی مقدار معلوم درست کار می‌کند یا نه. دقت گفتار فارسی، قیمت واقعی تأمین‌کننده، رضایت بیمار یا اثر کسب‌وکار را ثابت نمی‌کنند. وجود فیلد رضایتِ خیالی مجوز پردازش ضبط واقعی نیست.

## نسخهٔ تازه بسازید

از ریشهٔ مخزن، پوشهٔ تازه یا خالی انتخاب کنید:

~~~sh
python scripts/make_synthetic_fixtures.py /tmp/new-synthetic-fixtures
~~~

ابزار فایل موجود را بازنویسی نمی‌کند. پیش از اجرای ابزار بعدی، فهرست داده و برچسب‌های مورد انتظار را بررسی کنید. ابزار آموزش برای این نمونه‌ها به حالت صریح آزمون ساختگی نیاز دارد.

## کار با ضبط واقعی و مجاز

برای پژوهش واقعی، اصل ضبط، مجوز شرکت‌کننده، رکورد لغو رضایت و وزن مدل را در ذخیره‌ساز خصوصیِ تأییدشده نگه دارید. فهرست دادهٔ تازه‌ای بسازید که به همان مجوزها وصل باشد. پیش از انتخاب مدل، تقسیم‌های جدا بر پایهٔ گوینده و مرکز را ثابت کنید، بخش آزمون نهایی را کنار بگذارید و نسخهٔ مدل و روش رمزگشایی را ثبت کنید.

[راهنمای پژوهش](../../docs/research.fa.md) روش کامل ارزیابی و تفسیر خطای فیلدهای حساس را توضیح می‌دهد. دادهٔ ساختگی را با نتایج آزمون واقعی مخلوط نکنید.
