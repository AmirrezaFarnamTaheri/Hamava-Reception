# هم‌آوا | Hamava Reception

[English](README.md) | فارسی

هم‌آوا سامانه‌ای فارسی‌محور برای پذیرش مراکز نوبت‌محور است. این محصول سرویس نوبت‌دهی تراکنشی، محیط کار راست‌به‌چپ کارکنان، گفت‌وگوی مراجعه‌کننده، پردازش اختیاری صوت و نسخه‌های همراه ویندوز و اندروید را یکپارچه می‌کند. مرجع نهایی اطلاعات مرکز سرور است و برنامه‌های همراه پایگاه نوبت مستقل ندارند.

**نسخهٔ فعلی کد منبع: 0.2.2.** این مخزن نامزد توسعه/انتشار کد منبع است و **به معنی انتشار عمومی امضاشده یا تأیید بهره‌برداری واقعی** برای مرکز، مخابرات، کاربرد بالینی، پرداخت یا مدل گفتار نیست. اطلاعات بیماران، مراکز، قیمت‌ها، صوت‌ها و داده‌های پژوهشی نمایشی و ساختگی‌اند. سرویس‌های بیرونی تا زمان پیکربندی و پذیرش صریح غیرفعال می‌مانند.

## راه‌اندازی سریع در محیط نمایشی جداگانه

پیش‌نیازها: **Python 3.12**، **Node.js 24** و npm؛ برای آزمون‌های رمزگشایی صوت FFmpeg نیز لازم است. پایگاه دادهٔ عملیاتی PostgreSQL 16 است و نمایشی تک‌سیستمی از SQLite استفاده می‌کند. دستورات زیر را از ریشهٔ مخزن اجرا کنید:

~~~sh
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade -r requirements-bootstrap.txt
python -m pip install -c requirements.lock.txt '.[test,media]'
npm --prefix frontend ci
npm --prefix frontend run build
cp .env.example .env
set -a; . ./.env; set +a
python -m uvicorn receptionist.main:app --host 127.0.0.1 --port 8000 --no-access-log
~~~

در ویندوز فعال‌سازی محیط مجازی و بارگذاری متغیرهای محیطی را با دستورهای متناظر انجام دهید؛ مثال بالا مخصوص پوسته‌های POSIX است. نشانی **http://127.0.0.1:8000** محیط کارکنان و **http://127.0.0.1:8000/talk/bahar** گفت‌وگوی مراجعه‌کنندهٔ ساختگی است. حساب مالک نمایشی: `owner@example.test` با گذرواژهٔ `DemoReception2026!`؛ **هرگز** این مشخصات و حالت نمایشی را در مرکز واقعی استفاده نکنید. گفت‌وگوی متنی به سرویس گفتار نیازی ندارد.

برای اجرای کارهای پس‌زمینه، پنجرهٔ دیگری با همان تنظیمات باز کنید:

~~~sh
python -m receptionist.worker
~~~

وقتی کارگر مستقل اجرا می‌شود، در فرایند API مقدار `RUN_WORKER=false` بماند. بدون شناخت هماهنگی و بازیابی کارها، کارگر تکراری اجرا نکنید.

## قابلیت‌های اصلی

- رزرو موقت، ثبت و جابه‌جایی و لغو نوبت به‌صورت تراکنشی، کنترل تداخل و زمان‌های حائل، اجرای تکرارپذیرِ امن، رویدادهای حسابرسی و وظایف پیگیری.
- درک تاریخ شمسی و زبان فارسی، گفت‌وگوی مبتنی بر رضایت آگاهانه، پاسخ‌های تأییدشده، بازخوانی تصمیم و ارجاع امن به کارکنان.
- مدیریت دسترسی کارکنان در محدودهٔ هر مرکز، سیاست خدمات و اطلاعات مصوب، مرجع تقویم، وضعیت پیام‌ها، فهرست انتظار، بیعانه، بازپرداخت و اختلافات، حریم خصوصی و کنترل تأمین‌کنندگان.
- اتصال اختیاری AudioSocket/Asterisk، ‏LiveKit، پردازش گفتار محلی و سایر سرویس‌های بیرونی، فقط با کنترل مستقل مجوز، مسیریابی، هزینه و تطبیق نتیجه.
- رابط مشترک React و میزبان‌های Electron برای ویندوز و Capacitor برای اندروید؛ برنامه‌های همراه به API مرکز متصل‌اند و سرور مستقلی نیستند.

## اعتبارسنجی

~~~sh
python -m ruff check backend scripts services
python -m pytest -q
python scripts/protocol_conformance.py --output artifacts/backend/protocol-conformance.json
npm --prefix frontend run build
npm --prefix frontend run test:browser-launch
npm --prefix apps/desktop test
node scripts/check-versions.mjs
node scripts/check-docs.mjs
node --test scripts/check-docs.test.mjs
~~~

گردش‌کار تأیید GitHub علاوه بر این‌ها آزمون‌های جداگانهٔ PostgreSQL، مرورگر و اجرای کانتینر را انجام می‌دهد. قبولی آزمون ساختگی به معنای تأیید صوت واقعی تلفنی، تسویهٔ بانکی، دستگاه فیزیکی، امضای انتشار یا مجوز مرکز نیست. برای نتیجهٔ هر نسخه باید اجرای CI همان بازنگری بررسی شود؛ گزارش‌های قدیمی سند آزمون روز نیستند.
